### 4. Rétention des archives : le moteur n'en a AUCUNE

Vérifié dans le code : `state.py` a bien un `prune_logs(state_dir, name,
keep_days)`, piloté par `log_keep_days = 30` dans `config.toml` — **mais
il ne concerne que les logs**. `ARCHIVE_DIRNAME = ".gdrive-sync-archive"`
n'apparaît que dans `runner.py` (`--backup-dir1/2`) et dans `config.py`,
où l'exclusion `\.gdrive-sync-archive/**` est rendue **obligatoire** avec
ce commentaire :

```

  (croissance sans fin) »
```

Autrement dit : le moteur se protège de l'emballement, **mais il ne purge
jamais**. Chaque run qui modifie ou supprime un fichier crée un dossier
horodaté qui reste là indéfiniment.

`~/GoogleDrive/.gdrive-sync-archive` et

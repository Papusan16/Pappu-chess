# _fonds/parties_test/ — banc d'essai des détecteurs et démonstrations

Parties **réelles** conservées comme matériel de test stable pour les
détecteurs (mauvais fou, avant-poste, pion passé…) et les démonstrations
de l'encyclopédie.

## Ce que c'est — et ce que ce n'est pas

- **Ce n'est PAS du fonds pédagogique.** Aucune doctrine, aucune leçon
  arbitrée ici : ces PGN sont du **matériel de test**.
- **C'est un banc d'essai versionné.** Une position rejouable, identique
  d'une session à l'autre, contre laquelle on vérifie qu'un détecteur dit
  la bonne chose (et pas de faux positif).

## Pourquoi les versionner

Ces parties doivent survivre aux conversations. Exemple :
`ounkar6-papu_san-2026-07-18.pgn` a servi **toute la validation du
détecteur de mauvais fou** (le fou f8 aux coups 7/12/14/15, faux positif
de l'ancienne définition) — et n'existait jusqu'ici que dans une
conversation, donc perdable. Consignée ici, elle reste rejouable par
n'importe quelle session future.

## Convention

- Un fichier PGN par partie, en-têtes chess.com complets inclus.
- Nom : `<blanc>-<noir>-AAAA-MM-JJ.pgn`.
